Моя неделя — веб-приложение для iPhone

Что умеет:
• дела по дням недели;
• переход между неделями;
• время и категории;
• галочки "выполнено";
• данные сохраняются на устройстве;
• работает офлайн после первого открытия;
• можно добавить на главный экран iPhone;
• можно выгрузить отдельное дело в Календарь (.ics).

Важно про напоминания:
Обычная веб-страница не может гарантированно присылать локальные уведомления на iPhone, когда приложение полностью закрыто.
В этой версии напоминание срабатывает, пока приложение открыто.
Для надежных push-уведомлений нужна опубликованная PWA с сервером push-уведомлений либо нативное iPhone-приложение.

Как запустить:
1. Файлы нужно разместить на любом HTTPS-хостинге.
2. Открой адрес сайта в Safari на iPhone.
3. Нажми "Поделиться".
4. Выбери "На экран Домой".
5. После этого планер появится как отдельная иконка.

Для быстрого теста на компьютере можно открыть index.html, но установка как PWA и service worker требуют HTTPS/localhost.
