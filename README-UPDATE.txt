Финальное обновление «Моя неделя»

Вкладки:
1. Неделя — еженедельные повторяющиеся дела с отдельными галочками на каждую неделю.
2. Календарь — ручное добавление событий, appointments и разовых дел: дата, время, место, заметка, выбор напоминания.
3. Заметки — свободные заметки.

Важно:
Эта статическая GitHub Pages-версия хранит данные локально на iPhone. Она не может сама читать Gmail, делать веб-поиск в фоне или гарантировать системные push-уведомления, когда веб-приложение закрыто. Эти функции требуют внешней автоматизации/серверной части либо интеграции с системным календарём.

Для обновления текущего GitHub Pages достаточно заменить index.html и sw.js файлами из этого архива.
